# Shareables

Data packs for SetupMan 0.25.0 or newer. Download a pack and add it with **Settings → Data packs → Import data pack**
(or drop the file on any SetupMan page). Imported laps carry an External badge with the sender's initials: you can
compare them with your own laps in Lap analysis and make one your reference lap, but they never count as your own.
